# 🕷️ Spider-Man Outline Animation

A creative web animation project that brings Spider-Man to life through an animated outline drawing, followed by a solid black fill effect. Built using HTML, CSS, and JavaScript.

## 🌐 Live Demo

**[View the Live Website](https://saurav56295.github.io/spiderman-outline-animation/)**

## ✨ Features

- 🕸️ Animated Spider-Man outline drawing effect
- 🖤 Black fill animation after the outline is completed
- 🔄 Replay Animation button to restart the animation
- 🎨 Clean and minimal visual design
- 📱 Web-based project that runs in a modern browser

## 🛠️ Technologies Used

- **HTML5** — Structure of the webpage
- **CSS3** — Styling, layout, and animation effects
- **JavaScript** — Animation sequence and replay functionality
- **SVG** — Scalable vector paths for the Spider-Man outline
- **Git & GitHub** — Version control and project hosting
- **GitHub Pages** — Free website deployment

## 🚀 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Saurav56295/spiderman-outline-animation.git
   ```

2. Open the project folder:

   ```bash
   cd spiderman-outline-animation
   ```

3. Open `index.html` in your browser, or use the **Live Server** extension in Visual Studio Code.

## 🎮 How to Use

1. Open the live demo.
2. Watch the Spider-Man outline animation.
3. Wait for the black fill effect to appear.
4. Click **Replay Animation** to watch it again.

## 📌 Project Goals

This project explores SVG-based drawing effects, web animations, and JavaScript interactions to create an engaging visual experience using fundamental frontend technologies.
